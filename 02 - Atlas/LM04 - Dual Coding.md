# LM04 — Dual Coding
*Deep dive + project ([[DR-009 - Learning Method Deep Dives|DR-009]]). Hub: [[LM00 - Learning Methods Hub|Learning Methods]] · Method in practice: [[how-i-study]] §1*

> [!NOTE] Evidence: **Moderate**

## In plain words
Put the same idea into words **and** a picture (a diagram, a timeline, a circuit), and link the two.

## The evidence, honestly
Paivio's dual-coding theory: memory has verbal and visual systems, and items coded in both are easier to recall.
Mayer's multimedia research: words plus relevant diagrams beat words alone for learning how systems work.
Careful: Dunlosky et al. (2013) rated "imagery for learning text" **low**. Decorative pictures don't help. Diagrams of the actual structure do.
This is not "learning styles": everyone benefits from a good diagram ([[Learning Styles Myth]]).

## Using it in EECS
- EECS is full of natural pictures: circuit schematics, memory layouts, state machines, timing diagrams, call stacks, packet headers.
- Draw each one yourself before you look at the book's version.

## Common mistakes
- Copying the textbook figure, which is just rereading with a pen.
- Pretty diagrams with no labels or captions.
