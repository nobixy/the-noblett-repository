# LM00 — Learning Methods Hub
*Every learning method and framework in this vault, each with a deep dive and a hands-on project ([[DR-009 - Learning Method Deep Dives|DR-009]]). Use this alongside [[how-i-study]] §1 (the short version) and [study-protocols](<../study-protocols.md>) (the protocol codes R, F, W, S, I, C, D, T, V). Note first: "learning styles" are a myth ([[Learning Styles Myth]]); these are methods, and they work for everyone.*

## The methods
*Read the deep dives as companion reading when a protocol is new to you or stops working ([[how-i-study#2a. Reading Ramp|Reading Ramp]]). The order below runs from no-code to intermediate Python. The projects are **optional mini-projects**: nothing in the curriculum depends on them, they are not scheduled, and if you pick one up it counts as your one open build project while you work on it (rule 2 in [[00 - Start Here|Start Here]]).*

## Evidence key
- **Strong:** many experiments and meta-analyses agree.
- **Moderate:** good experiments, with limits.
- **Practitioner / anecdotal:** experienced people recommend it, but it hasn't been tested. Use it, and watch whether it works for you.
- **Contested:** the claims outrun the data.
