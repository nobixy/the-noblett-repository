# LM00 — Learning Methods Hub
*Every learning method and framework in this vault, each with a deep dive and a hands-on project ([[DR-009 - Learning Method Deep Dives|DR-009]]). Use this alongside [[how-i-study]] §1 (the short version) and [[B0 - The Deep Learner's Toolkit|B0]]. Note first: "learning styles" are a myth ([[Learning Styles Myth]]); these are methods, and they work for everyone.*

## Suggested order
*Ordered by when they fit the Starter Sprint and by coding skill: no-code or Scratch first, Python beginner next, intermediate Python last. Each week's deep-dive note is that week's 10–30 minutes of companion reading ([[how-i-study#2a. Reading Ramp|Reading Ramp]]); the project rides on that week's build.*

## Where the hours come from
- **[[B0 - The Deep Learner's Toolkit|B0]]** (+5 h of project work, existing hours): replaces reading the long *8 Core Cognitive Study Systems* section front to back; the deep dives are that reading, done project-first.
- **[[BM - Bedrock Mathematics|BM]]** (+10 h of project work, existing hours): the Shuffle Drill replaces the Khan practice sets beyond the unit tests (the unit tests stay); the why-ladders for invert-and-multiply and negative × negative count as Build Requirement 2's Feynman explanations.
- **[[BW - Bedrock English and Grammar|BW]]** (+5 h of project work, existing hours): replaces 5 of the 10 parsing sentences and 5 of the 10 de-nominalization drills; the diff tool does copywork's comparison step.
- **[[P1 - Learning How to Learn|P1]]** (+3 h of project work, existing hours): replaces the optional *Ultralearning* skim and the bash-template part of Build 2; the SM-2 app absorbs the Week 9 Leitner app (4 h).
- **[[P4 - Programming On-Ramp|P4]]** (+3 h of project work, existing hours): replaces rewatching CS50 lectures; you annotate the lecture source code instead.
- **[[P5 - Tooling|P5]]** (+11 h of project work, existing hours): counts as the Missing Semester exercises for lecture 2 (shell tools and scripting), 4 (data wrangling) and 6 (version control): the exercises are your own tools.
- **[[P2 - Reading, Thinking, and Writing|P2]]** (+0 h of project work, existing hours): no new time: these are P2's existing build 2 and Week 11 puzzles.

## Evidence key
- **Strong:** many experiments and meta-analyses agree.
- **Moderate:** good experiments, with limits.
- **Practitioner / anecdotal:** experienced people recommend it, but it hasn't been tested. Use it, and watch whether it works for you.
- **Contested:** the claims outrun the data.
