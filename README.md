# The Noblett Repository

A self-directed EECS program (MIT Course 6-3 SB + MEng equivalent) inside a lifelong learning system, kept as an Obsidian vault.

**Start here:** [00 - Start Here](00%20-%20Start%20Here.md) (in Obsidian: [[00 - Start Here]]). It is the one hub: dashboard, the ordered path of every block with checkboxes, and the operating rules.

## Layout
- Root: `00 - Start Here`, `how-i-study` (study method), `log` (daily-log dashboard), `Calendar` and `Telemetry Log` (written by the iPhone Shortcut automation, so they stay put), `verify_curriculum.py`.
- `01 - Curriculum/`: one folder per stage, in study order (`00 - Phase -1 Bedrock` … `06 - Year 5`), then `07 - Optional Electives`, `08 - Specialization Tracks`, `09 - Supporting Systems`. File names carry the block number (`B01 - CS61A`, `P3 - Math Prerequisites`, `T07 - TinyML and Edge AI`).
- `02 - Notes/`: topic indexes plus the paper-reading, writing and breadth hubs.
- `03 - Projects/`: the projects hub and every build spec.
- `04 - Reference/`: the source program PDF, appendices, and the book shelf.
- `05 - Decisions/`: decision records `DR-001` onward.
- `06 - Templates/`, `07 - Daily Log/`.
- `99 - Archive/`: cut blocks, and the list of what was removed on 2026-10-10 with the git commit to restore it from.
- Check the curriculum: `python3 verify_curriculum.py` (read-only).

Personal financial, health, identity and relationship data never goes in this repo (Operating Rule 9).
