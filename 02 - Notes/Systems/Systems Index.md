# Systems Topic Notes
*Per Appendix B.5: One atomic note per systems mechanism or architectural principle.*

## Core Focus Areas
- **Architecture & Memory:** Caches, virtual memory, paging, TLBs, pipeline hazards
- **Operating Systems:** Traps, context switching, scheduling, page tables, xv6
- **Concurrency & Synchronization:** Mutexes, semaphores, lock-free queues, race conditions
- **Storage & Databases:** Buffer pool management, B+ trees, WAL/ARIES recovery, MVCC
- **Distributed Systems:** Consensus (Raft/Paxos), replication, vector clocks, sharding
