# 03 - Engineering Practice

Applied tooling, building, testing, and operational skills that run parallel to theory.

## Continuous Engineering Curriculum
- **Version Control (Git)**: Branching, rebasing, resolving conflicts, semantic commits.
- **Operating Systems (Linux)**: Command-line fluency, shell scripting, file permissions, processes.
- **Debugging & Profiling**: GDB, Valgrind, Chrome DevTools, flame graphs.
- **CI/CD**: GitHub Actions, automated testing pipelines, deployment workflows.
- **Testing**: Unit testing, integration testing, property-based testing, test-driven development (TDD).
- **Containerization (Docker)**: Writing Dockerfiles, docker-compose, container orchestration.
