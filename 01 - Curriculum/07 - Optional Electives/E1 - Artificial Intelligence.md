## 🎯 Why This Block Matters
Artificial Intelligence is a core pillar of modern computer science. Understanding search, adversarial games, constraint satisfaction, Markov Decision Processes (MDPs), and Reinforcement Learning forms the classical foundation required before studying deep neural networks.

## 📖 Primary Syllabus & Core Content
- [ ] Uninformed & Informed Search (BFS, DFS, A*)
- [ ] Adversarial Search (Minimax, Alpha-Beta Pruning)
- [ ] Constraint Satisfaction Problems (CSPs)
- [ ] Markov Decision Processes (MDPs) & Value Iteration
- [ ] Reinforcement Learning (Q-Learning)
- [ ] Bayes Nets & Hidden Markov Models (HMMs)

## 🛠️ Build Requirement
Complete the classic Berkeley CS188 Pacman projects in Python. Build agents that play Pacman using A* search, Minimax with Alpha-Beta pruning, and Q-learning. Ensure the RL agent learns to navigate the board optimally.
