## 🎯 Why This Matters
Security is essential for robust systems. 6.1600 is MIT's undergraduate entry point to security and the on-ramp to the graduate courses used in [[T03 - Advanced Security and Cryptography|Track 3]] (6.5610 applied crypto, 6.5660 systems security).

## 📖 Primary Syllabus & Core Content
- [ ] Authentication: passwords, hashing, collision resistance, Merkle trees
- [ ] Cryptographic tools: MACs, digital signatures (RSA), authenticated encryption, key exchange, public-key encryption, PKI
- [ ] Transport security: TLS
- [ ] Platform security: isolation, privilege separation, hardware security, side channels
- [ ] Software security: memory safety, fuzzing, symbolic execution, runtime defenses
- [ ] Human and legal side: end-user security, computer-crime law
