## 📖 Primary Syllabus & Core Content
- [ ] Sorting: Mergesort, Quicksort, Heapsort, Radix/Counting sort
- [ ] Data Structures: Binary search trees, AVL trees, Hash tables, Priority queues
- [ ] Graph Algorithms: BFS, DFS, Dijkstra, Bellman-Ford, DAG shortest paths
- [ ] Dynamic Programming: 5-step DP framework (subproblems, guess, recurrence, memoize/table, solve original problem)
- [ ] Practice: Zingaro chapters 6–10 in parallel; compete in 1 rated Codeforces contest/month; read Algorithms to Live By

---

## 🛠️ Build Requirement
Implement every major data structure and algorithm from scratch in `c` and `python`. Verify all implementations with exhaustive unit tests and fuzzing under `pytest`, check memory safety with `valgrind`, benchmark against large random graph inputs, and typeset formal runtime and correctness proofs in `latex`.
