## 📖 Primary Syllabus & Core Content
- [ ] Divide and conquer: Medians, FFT, matrix multiplication
- [ ] Dynamic Programming: Advanced memoization, matrix-chain multiplication, optimal BST
- [ ] Greedy algorithms: Matroids, fractional knapsack
- [ ] Network Flow: Ford-Fulkerson, Edmonds-Karp, Min-Cut Max-Flow theorem, bipartite matching, disjoint paths
- [ ] Linear Programming: Formulations, duality, Simplex algorithm
- [ ] NP-Completeness: Reductions (3-SAT, Vertex Cover, Clique, Subset Sum, Hamiltonian Path)
- [ ] Approximation Algorithms: Set Cover, TSP, vertex cover heuristics

## 🛠️ Build Requirement
Implement Edmonds-Karp network flow, Dinic's blocking flow algorithm, a Primal-Dual Simplex solver, and spectral graph partitioning algorithms from scratch in `c++` and `python`. Verify correctness and edge-case invariants with `pytest`, benchmark on DIMACS challenge graphs, and typeset rigorous mathematical proofs in `latex`.
