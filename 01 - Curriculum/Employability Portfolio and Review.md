# Employability Portfolio and Review

*Due by the end of Year 4, before the Capstone proposal. Not a gate for specializations ([[DR-001 - Program Scope, Phases, and Timeline|DR-001]]).*

The milestone specification for reaching baseline professional readiness. It closes Phase 5 of the Core Spine in [[00 - Start Here]].

## Requirements
- **Required Portfolio Projects**:
  1. A systems-level project (e.g., memory allocator, key-value store).
     - *Source:* polish an existing build: the malloc lab from [[Computer Systems|Block 9]], or the BusTub storage engine from [[Databases|Block 21]].
  2. A full-stack web application with user authentication and database.
     - *Source:* [[Full-Stack and Product Engineering|Track 15]]. The minimum, whether or not Track 15 is one of your two tracks, is Full Stack Open Parts 0–5 (≈6 parts × 15–20 h). Parts 4–5 cover token authentication, user administration and testing, and Part 13 adds a relational database.
  3. A robust API or microservice demonstrating CI/CD and testing.
     - *Source:* [[Software Construction|Block 17]] discipline + the CI/CD and Docker rows of [[03 - Engineering Practice]].
- **Technical Resume Standards**: 1-page format, quantifiable impact, no jargon, strictly relevant technologies.
- **Code Review Checklist**: Readability, modularity, security, performance, test coverage.
- **Production Deployment Criteria**: Hosted online, automated build process, proper environment variable management, monitoring/logging.

## 🏁 Done when
> [!IMPORTANT]
> All three projects are public, deployed where applicable, green in CI, and reviewed by at least one outside engineer against the Code Review Checklist; the resume is written and reviewed.
