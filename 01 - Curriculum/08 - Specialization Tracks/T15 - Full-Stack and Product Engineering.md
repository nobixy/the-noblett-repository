## 🎯 Why This Track Matters
Most software jobs ship web products. The core program teaches what sits under a web app (networking, databases, systems) but never builds one end to end. This track does: frontend, backend, auth, data, tests, deployment, and the product and design judgment that decides what to build.

## 📚 Core Courses

### Course 1: Full Stack Open (University of Helsinki, fullstackopen.com)
- Free; Parts 0–14, each roughly one week of 15–20 hours.
- Core (Parts 0–5): web fundamentals, React, Node.js + Express, MongoDB, testing, token authentication and user administration.
- Extensions: state management (6), React Router and webpack (7), GraphQL (8), TypeScript (9), React Native (10), CI/CD (11), containers (12), relational databases (13), Next.js (14).
- Do Parts 0–5, 9, 11, 12 and 13 at minimum.

### Course 2: Software Engineering for Products (pick one)
- **Berkeley CS169A, Introduction to Software Engineering** (cs169.org): Agile, user stories, behavior- and test-driven development, design patterns, refactoring legacy code, all while building and deploying Software as a Service in Rails. Free text: Fox & Patterson, *Engineering Software as a Service*, 2nd ed.
- **MIT 6.1040 Software Design** (61040.github.io): concept design, UX and needfinding, and building with Node/Express, MongoDB and Vue, including LLM-based features.

## 🏆 Capstone Build Deliverable
A deployed, tested, multi-user web product with authentication, a relational database, CI/CD and monitoring, used by real people other than you. Ship a written design doc and a postmortem of one real incident or failed assumption.
