## 🎯 Why This Block Matters
The most under-appreciated course in the MIT degree. How to write complex code that does not rot.

---

## 📖 Primary Syllabus & Core Content
- [ ] Specifications and behavioral contracts (preconditions, postconditions)
- [ ] Testing strategies, glass-box vs black-box, partition coverage
- [ ] Abstract Data Types (ADTs), Representation Invariants (RI), Abstraction Functions (AF), checkRep()
- [ ] Immutability, avoiding representation exposure
- [ ] Recursive data types, grammars, and parser generators
- [ ] Concurrency, thread safety arguments, locks, and monitors
- [ ] Ousterhout, A Philosophy of Software Design, 2nd ed.

---

## 🛠️ Build Requirement
Take your clox or Monkey interpreter from Block 12 and completely rebuild it under test: formal specifications first, explicit rep invariants, abstraction functions, and an exhaustive test suite.

## 🏁 Done When
