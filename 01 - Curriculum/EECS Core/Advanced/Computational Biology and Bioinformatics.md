## 🎯 Why This Track Matters
The intersection of algorithms, machine learning, and genomics represents one of the most critical frontiers in modern science. This track transitions you from pure software engineering to biological data science, algorithms for sequence alignment, hidden Markov models for gene finding, and single-cell RNA-seq analysis.

## 🔗 Prerequisites
*What must you have mastered before starting this block?*
- [[Algorithms II]]
- [[Probability]]
- [[Statistics]]
- [[Introduction to Machine Learning]]

## 📖 Primary Syllabus & Core Content
- [ ] Rosalind Bioinformatics Stronghold (algorithmic foundations)
- [ ] Sequence Alignment (Dynamic Programming, Needleman-Wunsch, Smith-Waterman)
- [ ] Genome Assembly (De Bruijn Graphs, Eulerian Paths)
- [ ] Phylogeny (Distance Matrices, UPGMA, Neighbor-Joining)
- [ ] Hidden Markov Models (HMMs) for Gene Prediction and Motif Finding
- [ ] Transcriptomics and Single-Cell RNA Sequencing Analysis
- [ ] Deep Learning applied to Genomics and Protein Folding (e.g., AlphaFold architecture)

## 🛠️ Build Requirement
1. **The Rosalind Stronghold:** Solve the core 50 algorithmic challenges on Rosalind.
2. **De Novo Genome Assembler:** Build a de novo genome assembler from scratch in C++ or Rust using De Bruijn graphs to reconstruct a genome from simulated short reads.
3. **Biological ML Pipeline:** Implement a pipeline using PyTorch to predict transcription factor binding sites from DNA sequence data.

## 🏁 Mastery Criteria & Assessments
> [!IMPORTANT]
> You can explain the algorithms behind modern aligners (like BWA or Bowtie), correctly formulate an HMM for gene finding, and your genome assembler reconstructs the target sequence with high fidelity.
