# E02 — Sound Patterns and Spelling Rules

**In this stage you will:** learn how English letters map to sounds, learn the six spelling rules that explain most suffix errors, and re-tag your error log by rule so you can see which rules you break most.

**Time:** about 20 hours over 3 weeks.

**Before you start:** E01 done. Your `spelling-log.tsv` has 30+ entries.

---

## Why rules, if English is so irregular?

Because rules turn hundreds of separate facts into a few procedures. "Stopped, running, bigger, hotter, beginning, occurred, preferred" are seven words to memorise, or one rule to apply. Rules are also how you spell a word you have *never seen written*, which is what you do every time you name a new variable or write a new message.

Spelling rules are a lot like code: a condition and an action. "**If** the word ends in one vowel plus one consonant, **and** the suffix starts with a vowel, **then** double the consonant." You will literally write some of these rules as code in the [Spelling Engine](projects/spelling-engine/spec.md) project and test them against real words. Programmers call that "testing a hypothesis against data." You will find the exceptions the same way.

## Part 1 — Letters and sounds (week 1)

English has 26 letters but about 44 sounds. So some sounds need two letters, and some letters make more than one sound. The patterns below explain most of it.

**Vowels:** a, e, i, o, u (and sometimes y). **Consonants:** all the other letters.

A **syllable** is one beat of a word with one vowel sound: *com-pu-ter* has three. Clap it if unsure.

### Pattern 1: Short vowels in closed syllables

A syllable that ends in a consonant usually has a **short** vowel sound.

| a | e | i | o | u |
| :-- | :-- | :-- | :-- | :-- |
| c**a**t, b**a**ck | b**e**d, s**e**nd | s**i**t, l**i**st | h**o**t, st**o**p | c**u**p, b**u**g |

### Pattern 2: Silent e makes the vowel long

A **long** vowel says its own name (A, E, I, O, U). An *e* at the end of a short word is silent, and it makes the vowel before it long.

| short | long (with silent e) |
| :-- | :-- |
| hat | hate |
| bit | bite |
| hop | hope |
| cub | cube |
| not | note |

This one pattern explains a big rule later: *hoping* (from hope) vs *hopping* (from hop). Keep it in mind.

### Pattern 3: Open syllables are long

A syllable that ends in a vowel usually has a long vowel: *go, me, hi, ro-bot, pa-per, mu-sic*.

### Pattern 4: Vowel teams

Two letters working together to make one vowel sound.

| Sound | Spellings | Examples | Hint |
| :-- | :-- | :-- | :-- |
| long A | ai, ay | rain, wait · day, play | *ay* at the end of a word, *ai* in the middle |
| long E | ee, ea | see, need · read, team | learn by word |
| long O | oa, ow | boat, road · show, slow | |
| long I | ie, igh, y | pie, tie · high, night · my, try | |
| "oo" | oo, ew, ue | moon · new · blue | |
| "ow" | ou, ow | out, sound · cow, down | |
| "oy" | oi, oy | coin, point · boy, enjoy | *oy* at the end, *oi* in the middle |
| "aw" | au, aw | cause, because · saw, draw | |

### Pattern 5: Vowel + r

An *r* changes the vowel before it.

- **ar** = car, start, array
- **or** = for, port, sort
- **er, ir, ur** all sound the same: h**er**, s**er**ver, b**ir**d, f**ir**st, t**ur**n, ret**ur**n. *This is a common error source.* There is no sound rule to choose between them; use word families (*serve → server, service*) and hooks.

### Pattern 6: Consonant teams

| Team | Sound | Examples |
| :-- | :-- | :-- |
| sh | "sh" | shell, push |
| ch | "ch" (or "k" in Greek words) | check, chip · **ch**aracter, s**ch**edule, te**ch** |
| th | "th" | the, thread, path |
| wh | "w" | which, when, while, where |
| ph | "f" | phone, graph, alphabet |
| ng | "ng" | string, long |
| ck | "k" right after a short vowel | back, stack, lock, check |
| tch | "ch" right after a short vowel | catch, patch, switch, fetch |
| dge | "j" right after a short vowel | bridge, edge, badge |

Notice the pattern in the last three: **after a short vowel**, English uses the longer spelling (*ck, tch, dge*). After a long vowel or another consonant it uses the short one: *back* but *bake*; *catch* but *reach*; *bridge* but *huge*.

### Pattern 7: Soft c and soft g

- **c** says "s" before **e, i, y**: **c**ent, **c**ity, **c**ycle, pro**c**ess, de**c**imal. Otherwise "k": **c**at, **c**ode, **c**ut.
- **g** often says "j" before **e, i, y**: **g**em, **g**iant, **g**ym, chan**g**e. Otherwise hard: **g**ame, **g**o, **g**un.

This is why *noticeable* and *changeable* keep their *e* (Rule 2 below): without the *e*, the *c* and *g* would be hard: "notic-able" would read as "noti-KAble."

### Pattern 8: The lazy vowel (schwa)

In most words, one syllable is **stressed** (said louder) and the others are not. Unstressed vowels often all sound like a lazy "uh": sep-**uh**-rate, def-**uh**-nite, gram-m**uh**r, cal-**uh**-dar. This lazy sound is called a **schwa**. It is the single biggest cause of vowel errors, because the sound gives you no clue.

**Fixes for schwa:**
1. **Spelling voice:** say it as spelled: "sep-A-rate", "gram-MAR", "cal-EN-dar".
2. **Related word where the vowel is stressed:** *definite* → *finite* (you can hear the *i*); *grammar* → *grammatical*; *competition* → *compete*; *preparation* → *prepare*.

### Silent letters

Some letters were pronounced long ago and stopped being said: **kn** (know, knowledge), **wr** (write, wrong), **gn** (sign, design), **mb** (climb, thumb), **gh** (light, through, thought), **l** (could, would, should, half, talk), **ps** (psychology), **h** (hour, honest).

Hook for silent letters: a related word often says the letter out loud: *sign → signal*, *design → designate*, *bomb → bombard*. And *could/would/should* are a family: learn one, get three.

## Part 2 — The six spelling rules (weeks 2–3)

These rules are about adding **suffixes** (endings like *-ing, -ed, -er, -ful, -ly, -s*). Most adult spelling errors happen right here.

A suffix that starts with a **vowel**: -ing, -ed, -er, -est, -able, -ence, -ous.
A suffix that starts with a **consonant**: -ful, -ly, -ment, -ness, -less, -s.

### Rule 1 — Doubling

**If** a word has **one** syllable, **one** vowel, and ends in **one** consonant (the "1-1-1" word), **and** you add a **vowel** suffix, **then double** the last consonant.

- stop → sto**pp**ed, sto**pp**ing · run → ru**nn**ing · big → bi**gg**er · plan → pla**nn**ed · hot → ho**tt**est
- Consonant suffix: no doubling: sad → sa**d**ness, ship → shi**p**ment.
- Never double **w, x, y**: fix → fixing, play → playing, show → showed.

**Longer words:** double only if the **stress is on the last syllable**.
- be-**GIN** → begi**nn**ing · oc-**CUR** → occu**rr**ed, occu**rr**ence · pre-**FER** → prefe**rr**ed · re-**FER** → refe**rr**ed · com-**MIT** → commi**tt**ed
- **O**-pen → ope**n**ed · **VIS**-it → visi**t**ed · **TAR**-get → targe**t**ed · **LIM**-it → limi**t**ed · **BUD**-get → budge**t**ed

> **Why does this rule exist? [W]** Look back at Patterns 1 and 2. *Hoping* (from *hope*) has a long O. *Hopping* (from *hop*) has a short O. The double letter is a signal to the reader: "the vowel before me is short." Without doubling, *hoped* and *hopped* would look the same. Every rule in this list exists to stop a misreading. Find the misreading, and you will remember the rule.

> *American vs British:* British English doubles *l* even when unstressed (travelled, cancelled, modelling). American English follows the stress rule (traveled, canceled, modeling). Pick one; stay consistent.

### Rule 2 — Drop the silent e

**If** a word ends in a **silent e** and you add a **vowel** suffix, **drop the e.**

- make → making · use → using, usable · write → writing (one *t*! the *i* is long) · hope → hoping · store → storage · compute → computing · type → typing, typist
- **Keep** the e before a **consonant** suffix: hope → hope**ful** · use → use**less** · complete → complete**ly** · manage → manage**ment** · state → state**ment**
- **Keep** the e after **soft c or g** before *-able* or *-ous* (Pattern 7): notice → notic**e**able · change → chang**e**able · manage → manag**e**able · courage → courag**e**ous
- **Exceptions to learn as a list:** tru**e** → **truly** · argu**e** → **argument** · nin**e** → **ninth** · judg**e** → **judgment** (US) · whol**e** → **wholly**

> **Why? [W]** The silent e's job is to make the vowel long (Pattern 2). A suffix starting with a vowel can do that job instead (*hop-ing*, open syllable → long), so the e is no longer needed. A consonant suffix can't do the job, so the e stays.

### Rule 3 — y to i

**If** a word ends in **consonant + y**, **change the y to i** before any suffix **except -ing**.

- try → tr**ie**d, tr**ie**s · but try**ing** · happy → happ**i**ness, happ**i**ly · easy → eas**i**ly · carry → carr**ie**d · copy → cop**ie**s · apply → appl**ie**d · query → quer**ie**s · study → stud**ie**d, study**ing** · dependency → dependenc**ie**s
- **Vowel + y: keep the y:** play → play**ed** · key → key**s** · delay → delay**s** · array → array**s** · enjoy → enjoy**ment** · destroy → destroy**ed**
- **Exceptions:** day → daily · pay → paid · say → said · lay → laid

> **Why keep y before -ing? [W]** Because *tri-ing* would put two i's together, which English avoids (the only common exceptions are *skiing* and *taxiing*).

### Rule 4 — i before e

**i before e** (bel**ie**ve, p**ie**ce, fr**ie**nd, f**ie**ld, ach**ie**ve), **except after c** when it makes the "ee" sound (re**cei**ve, **cei**ling, de**cei**ve, re**cei**pt), **or when it sounds like "ay"** (n**ei**ghbor, w**ei**gh, **ei**ght, v**ei**n).

**Honest note:** this rule has many exceptions. Learn them as a list: **weird, their, either, neither, seize, height, foreign, forfeit, leisure, protein, caffeine**, and words where *cie* is not "ee": **science, ancient, efficient, sufficient, species**. Put the exceptions in your flashcard deck.

### Rule 5 — Plurals

| Word ends in | Do this | Examples |
| :-- | :-- | :-- |
| most letters | add **s** | file → files, bit → bits |
| s, x, z, ch, sh | add **es** | bus → buses, box → boxes, patch → patches, hash → hashes |
| consonant + y | **y → ies** (Rule 3) | query → queries, library → libraries, proxy → proxies |
| vowel + y | add **s** | key → keys, array → arrays, delay → delays |
| f or fe | often **ves** | half → halves, leaf → leaves, life → lives · but roof → roofs, chief → chiefs |
| o | learn by word | photo → photos, video → videos, zero → zeros · hero → heroes, potato → potatoes |

**Irregular plurals you will see in technical writing:**

| Singular | Plural | Singular | Plural |
| :-- | :-- | :-- | :-- |
| child | children | matrix | matrices |
| person | people | vertex | vertices |
| mouse | mice | index | indices (math) / indexes (books, databases) |
| analysis | analyses | criterion | criteria |
| hypothesis | hypotheses | datum | data (usually used as singular now: "the data is") |
| axis | axes | appendix | appendices / appendixes |

### Rule 6 — Endings that sound alike

- **-ful** has **one l**: help**ful**, use**ful**, care**ful**, success**ful**. (But *full* the word has two.)
- **-ly** is added to the **whole** word: final + ly = fina**ll**y · real + ly = rea**ll**y · usual + ly = usua**ll**y · complete + ly = complete**ly** · (Rule 2 doesn't apply: *ly* is a consonant suffix). The double *ll* appears because the base word ends in *l*.
- **-able or -ible?** If you take off the ending and a **whole word** is left, it is usually **-able**: read**able**, accept**able**, depend**able**, port**able**. If what's left is not a word, usually **-ible**: vis**ible**, poss**ible**, terr**ible**, compat**ible**. (Not perfect, but a good first guess.)
- **-tion or -sion?** **-tion** is far more common (action, function, connection, operation). **-sion** comes after *l, n, r* in some words (expulsion, extension, version) and when it sounds like "zhun" (vision, decision, division, revision).
- **-ance or -ence?** No reliable rule. Learn by word family: *perform → performance*, *exist → existence*, *depend → dependence*, *refer → reference*. Hook: if the related word has a stressed vowel you can hear (*consequential* → consequ**e**nce), use it.

## Part 3 — Re-tag your error log

Go through every entry in `spelling-log.tsv`. Where a rule or pattern explains the error, add a rule tag (keep the old tag too, separated by a comma):

`rule-double`, `rule-drop-e`, `rule-y-i`, `rule-ie-ei`, `rule-plural`, `rule-suffix`, `pattern-schwa`, `pattern-silent`, `pattern-soft-cg`, `pattern-vowel-team`, `pattern-r-vowel`

Then count each tag. (By hand, or on Linux: `cut -f4 spelling-log.tsv | tr ',' '\n' | sort | uniq -c | sort -rn` — you'll understand every piece of that command by the end of Module 01.)

**Your top two tags are your focus for the rest of this stage.** Write them at the top of your log file.

## Part 4 — The three-week routine

Same shape as E01, with the lesson block focused on one pattern or rule per day.

| Week | Lesson focus (15–20 min/day) |
| :-- | :-- |
| 1 | Mon: Patterns 1–3 · Tue: Pattern 4 · Wed: Patterns 5–6 · Thu: Patterns 7–8 + silent letters · Fri: mixed dictation + re-tag your log |
| 2 | Mon: Rule 1 · Tue: Rule 2 · Wed: Rule 3 · Thu: Rules 1–3 mixed (Practice Set 1) · Fri: dictation |
| 3 | Mon: Rule 4 · Tue: Rule 5 · Wed: Rule 6 · Thu: Practice Sets 2 and 3 · Fri: self-check |

Each lesson day:
1. **Read** the rule. Cover it. **Write it from memory** in your own words, as an *if… then…* sentence [R].
2. **Why-ladder [W]:** what misreading does this rule prevent? Write the answer in one sentence.
3. **Subgoal labels [S]:** write the rule as numbered steps you could follow. Example for Rule 1:
   1. Does the suffix start with a vowel? If no, stop: don't double.
   2. Does the word end in one vowel + one consonant (not w, x, y)? If no, stop.
   3. Is the last syllable stressed (or is the word one syllable)? If no, stop.
   4. Double the last consonant, then add the suffix.
4. **Generate:** make 10 words using the rule, including 2 that *don't* follow it and say why.
5. **Spelling words** from your log, with Look–Say–Cover–Write–Check.

**Copywork [C]:** stay at Level 1. While diffing, notice every suffix in the passage and check which rule it follows.

### Practice Set 3 — Explain it [F] [W]

In one or two plain sentences each, explain:

1. Why *hopping* has two p's but *hoping* has one.
2. Why *noticeable* keeps its e but *noticing* doesn't.
3. Why *tried* has an i but *trying* keeps the y.
4. Why *beginning* doubles the n but *opening* doesn't.
5. Why *arrays* is right but *queries* changes the y.

<details>
<summary>Model answers (check the idea, not the wording)</summary>

1. *Hop* is a 1-1-1 word, so we double before *-ing*; the double letter tells the reader the *o* is short. *Hope* ends in silent e, which we drop before *-ing*; the single letter tells the reader the *o* is long.
2. The *e* keeps the *c* soft ("s" sound) before *a*. Before *i*, the *c* is soft anyway, so the e can go.
3. Consonant + y changes to i before a suffix, but not before *-ing*, because that would make two i's in a row.
4. *Be-GIN* is stressed on the last syllable, so it doubles. *O-pen* is stressed on the first syllable, so it doesn't.
5. *Array* ends in vowel + y (*ay*), so just add *s*. *Query* ends in consonant + y (*ry*), so y changes to *ies*.
</details>
